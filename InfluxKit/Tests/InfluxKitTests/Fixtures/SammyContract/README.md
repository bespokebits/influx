# Sammy contract files

These files are generated by the Sammy server's own tests, against the
origin `https://example.com` with made-up content, and copied here
byte for byte. `manifest.json` lists each one with its SHA-256 and the
contract version they belong to.

- **Never edit them by hand.** `SammyContractTests` checks every hash
  against the manifest, and the server's CI compares this manifest with
  its own.
- **Replace them together**, all of them and the manifest, with the set the
  server generates for a new contract version, in the same change that
  updates the code that reads or builds them.

What they cover: the feed list (with and without `account.id`), two feed
pages joined by `next_url`, a 304, the token responses, both OAuth metadata
documents, the client registration, the authorize request, the token and
revocation requests, and the approved and denied callbacks. ADR 0023 says
why.
